# Ultimate Leveling OS+

RPG-style productivity dashboard UI.

## Why it now works on GitHub Pages

The app now runs as a **no-build static site** (`index.html` + `src/main.js` + `src/styles.css`), so opening `https://<user>.github.io/<repo>/` works directly without Vite build output.

## Local preview

python3 -m http.server 4173
# open http://127.0.0.1:4173
